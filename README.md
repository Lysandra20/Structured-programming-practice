# Structured-programming-practice
Practice exercises to strengthen my ability to write, explain and organize small C programs using the programming structures concepts covered in class.
## Exercise 1 - Basic output
What the program does: Outputs information about a certain program offered at UCU
Concepts used: printf
How it works: Displays output to the user
## Exercise 2 - Input-Process-Output
Source - Deitel & Deitel, C How to Program, 9th Edition, chapter 1
What the program does: Asks user for integers and outputs the sum, average, product, smallest and largest integer
Concepts used: printf, scanf, integer variables
How it works: The user enters 3 integers, computes the necessary calculations, the program decides if the integer is the largest or smallest.
## Exercise 3 - Decisions
Source - Deitel & Deitel, C How to Program, 9th Edition, exercise 3.17
What the program does: Calculates monthly payable interest on mortgage
Concepts used: printf, scanf, float variables, if, else
How it works: Takes the mortgage amount and interest rate, calculates the monthly interest and displays the result
## Exercise 4 - Basic loop
Source - Deitel & Deitel, C How to Program, 9th Edition, exercise 4.16
What the program does: Displays a triangle using asterisks
Concepts used: printf, for loop
How it works: Uses a for loop to control the number of stars printed on each line, forming a triangle
## Exercise 5 - Loop with calculation
What the program does: Displays multiplication tables from 1 to 12
Concepts used: printf, integer variables, for loop
How it works: Uses a for loop to multiply numbers from 1 to 12 repeatedly
## Exercise 6 - Loop with user input
Source - Deitel & Deitel, C How to Program, 9th Edition, exercise 4.17
What the program does: Shows relationship between the users account balance and credit limit
Concepts used: printf, scanf, integer variables, float variables, if, else, for loop
How it works: Takes the account balance and credit limit as input, then uses conditions to determine their relationship
## Exercise 7 - Loop with decision
Source - Deitel & Deitel, C How to Program, 9th Edition, exercise 4.28
What the program does: Calculates weekly pay of different workers
Concepts used: printf, scanf, integer variables, while, float variables, if, else, switch
How it works: Takes each worker's hours and payrate and calculates weekly pay based on hours worked
## Exercise 8 - Interactive Console Program
What the program does: Displays a food menu to the user
Concepts used: printf, scanf, integer variables, do while loop, if, else if, else
How it works: Accepts choice made by user and displays the corresponding choice
